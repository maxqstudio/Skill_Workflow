# Code of Conduct

Skill Workflow welcomes technical participation that is focused on the project and respectful of other contributors.

## Expected conduct

Contributors should:

- discuss code, evidence, design, and tradeoffs rather than attacking people;
- give reproducible technical feedback when possible;
- respect privacy and never publish another person's private information;
- avoid harassment, threats, discrimination, sexualized conduct, or repeated unwanted contact;
- avoid intentionally disruptive behavior, spam, or attempts to bypass project security and governance controls.

Strong technical disagreement is acceptable. Personal abuse is not.

## Enforcement

Maintainers may edit or remove abusive content, close or lock disruptive discussions, reject contributions, or restrict participation when behavior materially harms contributors or project operation.

For conduct concerns that include sensitive personal or security information, do not post the details publicly. Use the private reporting path described in `SECURITY.md` when available.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions, release coordination, and other project-managed collaboration spaces.
